# 컴플라이언스 게이트 (M7) 운영 명세

> 이 사업에서 가장 큰 단일 손실은 콘텐츠 실패가 아니라 **누적 수익 몰수**와 **계정 정지**입니다. 그래서 M7은
> 성과 최적화보다 상위에 있으며, 어떤 학습 결과도 게이트 규칙을 완화할 수 없습니다. (설계서 §8)

## 1. 단일 경로 보장

- 생산에서 배포로 가는 경로는 `GateEngine.evaluate()` 하나뿐입니다. PASS를 받아야만 `content.status = approved`가 됩니다.
- 배포 엔진(M8)은 `approved`가 아닌 콘텐츠를 게시하지 않습니다(`PolicyViolation`).
- 게시 직전 **preflight**에서 다시 `G-00`(승인 상태)을 확인합니다. 우회 시도가 감지되면 BLOCK하고 `acvm_gate_rule_regressions_total`을 올립니다. 이 지표는 0을 유지해야 하며, 증가하면 Prometheus가 즉시 호출합니다.
- M10(학습)은 게이트 코드나 `GatePolicy`를 import하지 않습니다(`tests/unit/test_control_plane.py`가 강제).
- 규칙 세트 지문(`v1#<hash>`)이 모든 판정 기록에 남습니다. 어떤 규칙이 어떤 콘텐츠를 판정했는지 사후에 증명할 수 있습니다.

## 2. 판정 의미

| 판정 | 처리 | 콘텐츠 상태 |
|---|---|---|
| PASS | 링크 생성(M3) → 배포 예약(M8) | approved |
| FIX (제자리 수정) | 게이트가 직접 고친 뒤 최대 3회 재검사합니다. 렌더된 내레이션·자막이 바뀌면 재렌더합니다 | 그대로 → 재검사 |
| FIX (regenerate) | 대본 변형을 새로 만들고 렌더한 뒤 다시 판정합니다(최대 3라운드). 라운드를 넘기면 HOLD | draft |
| FIX (reschedule) | 콘텐츠는 적법하고 게시 시각만 옮깁니다(S-02) | approved |
| HOLD | 사람 승인 큐(`/holds`)에 올립니다. 승인되면 원래 계획대로 배포합니다 | gated |
| BLOCK | 폐기하고 사유를 감사 로그에 남깁니다 | blocked |

## 3. 규칙 (rule_set v1)

| ID | 단계 | 검사 | 실패 시 | 구현 메모 |
|---|---|---|---|---|
| D-01 | gate·preflight | 캡션·본문 **첫 줄**에 대가성 문구 | FIX | 하단에 있는 문구는 제거하고 첫 줄로 옮김(하단 표기 몰수 사례 대응) |
| D-02 | gate·preflight | 경제적 대가 명시(수수료 + 받음) | FIX | "#광고 #쿠팡파트너스"처럼 수수료 언급이 없으면 표준 문구로 교체 |
| D-03 | gate | 영상 0~3초 '광고' 오버레이 | BLOCK | 메타데이터(잠금·시작·길이·문구) 확인 + 프레임 검증. 검증 도구가 없으면 fail-closed |
| D-04 | preflight | 링크 허브 최상단 첫 텍스트 = 대가성 문구 | BLOCK | 저장된 허브 HTML을 파싱(script·style 무시) |
| C-01 | gate·preflight | 근거 없는 사실·효능 | FIX | 주장↔근거 숫자 일치 + 미등록 사실 문장 삭제 + (LLM 있으면) 대형 모델 판정 |
| C-02 | gate·preflight | 최상급·절대 표현 등 | FIX | 대체어로 순화하고, 효능·체험 위장·클릭 유도·보장 문구는 문장째 삭제 |
| C-03 | gate·preflight | 가격·할인이 실시간 가격과 일치 | FIX | 가격이 6시간 넘게 지났거나 불일치하거나 할인 문구면 해당 문장 제거. 게시 직전 M1이 가격을 재조회 |
| C-04 | gate·preflight | 규제 카테고리 | BLOCK | 카테고리 1024 + 규제 품목 사전 |
| R-01 | gate | 권리 원장 밖·만료 에셋 | BLOCK | 렌더 asset_ids ⊆ 원장 ∧ 라이선스 미만료 ∧ content_asset 연결 |
| R-02 | gate | 레퍼런스 유사도 | FIX→재생성 | 코사인 > 0.80 또는 5-gram > 15% (부모 콘텐츠 포함) |
| R-03 | gate | 상표·캐릭터·유명인·보이스 | HOLD | 고유명 사전 + 보이스 출처 원장 대조 + (LLM 있으면) 키프레임 비전 분류 |
| S-01 | gate | 계정 30일 내 중복 | FIX→재생성 | MinHash > 0.6 (대가성 문구 제외) |
| S-02 | gate·preflight | 쿼터·쿨다운 | FIX→재스케줄 | |
| A-01 | preflight | AI 생성물 표시 | FIX | `ai_label` → YouTube `containsSyntheticMedia`, TikTok `is_aigc`. 생성 이미지·영상을 쓴 구간에는 화면에 'AI 생성 장면'을 표시(타임라인 `ai_labels`, 스타일 옵션으로 끌 수 없음) |
| H-01 | gate | 신규 계정 14일, 신규 템플릿 10건 | HOLD | 템플릿별 승인 수가 10건 이상이면 자동 통과 |
| L-01 | preflight | 링크 서명·파트너 ID·상태 | BLOCK/HOLD | HMAC(서명키는 Vault 보관) + `lptag` 일치. 품절이면 HOLD하고 6시간 뒤 재시도 |
| G-00 | preflight | 승인되지 않은 콘텐츠 게시 시도 | BLOCK | 회귀 지표가 증가함 |

**생성형 AI 사용 원칙** (GPT Image · Higgsfield · Gemini, `acvm/integrations.py`, `m5_asset/ai_visuals.py`)
- **상품**: 생성·변형하지 않습니다.
  - AI 이미지는 *장면 비트*(문제 상황)에만 씁니다.
  - 권리 원장 `ai_generated_background`는 상품과 연결할 수 없습니다(M5 등록 정책·`check_override`).
  - 상품 사진의 모션은 카메라 모션만 허용합니다.
- **프롬프트 금지 항목**: 판매 상품, 포장, 브랜드, 로고, 읽을 수 있는 글자, 알아볼 수 있는 인물·얼굴.
- **Higgsfield**: AI 장면 정지 이미지에만 미세 모션과 카메라 무빙을 더합니다.
- **기록·비용**: 모든 생성물은 권리 원장(제공사·모델·프롬프트 해시)과 비용 원장(`ai.image`, `ai.video`)에 기록되고 일 예산을 넘지 않습니다.
- **모델 전환**: Claude 장애 시 Gemini로 전환되는 것은 인프라 오류(UpstreamError)일 때뿐입니다. 안전 판단으로 거절된 요청은 다른 모델로 우회하지 않습니다.

표준 대가성 문구는 다음과 같습니다(설정 `ACVM_GATE__STANDARD_DISCLOSURE`).

> 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

## 4. 회귀 테스트 (G2 조건: 100% 커버)

`tests/unit/test_m7_gate.py`는 모든 규칙을 위반 사례와 정상 사례 양쪽으로 검사합니다. `test_every_rule_is_covered`는 테스트가 없는 규칙이 하나라도 있으면 실패합니다. 규칙을 추가할 때는 반드시 테스트도 함께 추가해야 빌드가 통과합니다.
