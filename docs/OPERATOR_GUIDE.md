# ACVM 운영자 가이드

하루 15분 운영을 기준으로 씁니다(설계서 §8.4). 콘솔 주소는 개발에서 http://localhost:3000, 운영에서는 Cloudflare Access 뒤 콘솔 도메인입니다.

## 로그인 · 회원

- **로그인**: `https://<콘솔 주소>/login` — 이메일과 비밀번호. 5번 틀리면 15분 동안 잠깁니다.
- **회원가입**: `/signup` 에서 신청 → **소유자가 `회원 관리`에서 승인**해야 로그인됩니다(처음엔 열람자).
- **회원 관리** (소유자): 승인·거절, 역할(소유자·검수자·운영자·열람자) 변경, 정지·재활성화, 삭제, 계정 직접 만들기.
  자기 자신과 마지막 소유자는 강등·정지·삭제할 수 없습니다.
- **비밀번호 변경**: 왼쪽 아래 사용자 카드의 ⚙ → 비밀번호 변경. 다른 기기의 로그인은 자동으로 해제됩니다.
- **로그아웃**: 사용자 카드의 로그아웃 아이콘.
- 최초 소유자 계정은 서버에서 한 번 만듭니다 ([DEPLOY.md](DEPLOY.md) §11). 비밀번호는 DB에 해시로만 저장되고 어디에도 다시 표시되지 않습니다.

## 0. 처음 한 번: 운영 준비 (`/setup`)

`운영 준비` 화면은 실서비스에 필요한 항목을 초록(정상)·노랑(주의)·빨강(차단)으로 보여주고, 항목마다 해결 방법을 함께 적어 둡니다.

| 순서 | 할 일 | 화면 |
|---|---|---|
| 1 | 쿠팡 파트너스 Access Key / Secret Key 등록 | 운영 준비 › 비밀값 (입력 후 다시 표시되지 않음) |
| 2 | 파트너 ID(AF…)를 서버 설정 `ACVM_COUPANG__PARTNER_ID`에 넣고 `ACVM_COUPANG__SANDBOX=false` | 서버 설정 |
| 3 | 채널 계정별 토큰 등록 (Threads·Instagram·Facebook·YouTube·TikTok) | 계정 › 토큰 등록 |
| 4 | 실제 게시 전환 `ACVM_PLATFORMS__DRY_RUN=false` | 서버 설정 |
| 5 | (선택) AI 키 등록 — Claude·Gemini·GPT Image·Higgsfield·ElevenLabs. 등록 즉시 자동 적용 (아래 0-1) | 운영 준비 › AI 연동 |
| 6 | 법·정책 체크리스트 5개 확인 (오너) → **G0 통과** | 운영 준비 › G0 |
| 7 | 일 예산 설정 | 설정 |

> 키와 토큰은 서버의 비밀값 저장소에만 저장되고, 화면·로그·감사 기록 어디에도 다시 나타나지 않습니다.
> 저장소는 운영에서 Vault, 개발 PC에서는 `var/secrets.dev.json`입니다.

### 0-1. AI 연동 — 키만 넣으면 자동으로 켜집니다

`운영 준비 › AI 연동`에서 키를 붙여넣고 **등록 · 즉시 적용**을 누르면 다음이 차례로 일어납니다.
1. 서버가 키를 저장합니다.
2. 과금되지 않는 확인 요청으로 연결을 점검합니다.
3. 관련 단계를 바로 켭니다. 재시작은 필요 없습니다.

| 연동 | 키를 등록하면 자동으로 | 안전장치 |
|---|---|---|
| **Claude** | 대본 작성·검수, 명령 해석, 게이트 근거 판정·키프레임 비전 검사 | — |
| **Gemini** | Claude 키가 없으면 위 역할 전체를 수행. Claude 장애·한도 초과 시 자동 대체. 직접 촬영 영상 대본 추출(STT) | 안전 판단으로 거절된 요청은 다른 모델로 우회하지 않음 |
| **GPT Image** | 문제 상황 장면(비상품 비트) 배경을 대본에 맞춰 생성 | 상품은 절대 생성·변형하지 않음. 상품 비트는 실제 상품 사진만. 얼굴·브랜드·문구 금지 |
| **Higgsfield** | GPT Image 장면을 5초 모션 영상으로 변환해 그 비트에 배치. 스튜디오 툴의 'AI 모션' | AI 장면 이미지에만 사용. 상품 사진은 카메라 모션(무료)만 |
| **ElevenLabs** | TTS를 실제 음성으로 즉시 전환. 빠른 보이스 9종을 계정 음성에 자동 매핑. 미리듣기 갱신 | 내레이션·ASMR·차분한 음성은 매핑에서 뒤로 밀림 |

카드 상태 표시:
- **사용 중**: 정상
- **확인 전**: 등록 직후, 확인이 끝나지 않음
- **연결 불안정**: 네트워크 문제로 확인 실패. 계속 사용합니다
- **키 오류**: 키가 틀림. 사용하지 않습니다
- **일시 중지**: 키는 그대로 두고 자동 사용만 끔

카드 버튼:
- **연결 확인**: 다시 점검
- **일시 중지 / 다시 사용**: 자동 사용 끄기·켜기
- **키 삭제**: 해당 기능이 기본 방식(카드·Windows 음성·오프라인 작성기)으로 돌아감

AI 장면 규칙:
- **생성 범위**: 권리 원장에 직접 촬영본이나 스톡이 없는 문제 장면 비트에만, 쇼츠 한 편당 최대 2장·2클립.
- **기록**: 결과는 권리 원장에 'AI 생성 장면'으로 기록되고, 영상 해당 구간 왼쪽 위에 **'AI 생성 장면'**이 표시됩니다(AI 기본법 표시).
- **비용**: 일 예산에 반영됩니다. 예산이 부족하거나 생성이 실패하면 기존 카드로 자동 대체되어 렌더는 멈추지 않습니다.
- **기존 지정**: 스튜디오에서 직접 지정한 소스는 바꾸지 않습니다.

## 1. 매일 하는 일 (약 15분)

1. **HOLD 큐** (`/holds`, 약 10분): 영상·대본·캡션을 보고 `A` 승인 또는 `R` 반려합니다. 캡션 첫 줄의 대가성 문구는 자동으로 강조됩니다.
2. **알림 벨** (상단): 게이트 차단, 계정 쿨다운, 무효 클릭 의심, 토큰 갱신 실패를 확인합니다(약 2분).
3. **대시보드 › 학습** (약 3분): 증폭 후보와 채널별 G3(중앙값 ÷ 손익분기) 상태를 봅니다.

## 2. 콘텐츠를 만드는 세 가지 방법

### A. 명령 한 줄 (자판기)
`명령` 화면에 자연어로 입력합니다. 예: "주방 5개, 30대 여자 페르소나로 쇼츠 만들어서 스레드랑 인스타에 올려줘"
→ 계획 미리보기(상품 수·대상 계정·링크 위치·시간대·추정 비용·승인 방식)를 확인하고 승인하면 상품 선별 → 대본 → 렌더 → 게이트 → 예약 게시가 끝까지 자동으로 진행됩니다.
반복 작업은 `예약`에 "매일 오전 9시에 차량용품 10개"처럼 등록합니다.

### B. 쇼츠 스튜디오 — 한 편을 정성껏
1. **상품 선택**: 카테고리 또는 검색으로 찾습니다. 기회 점수(POS)가 높은 순으로 보입니다.
2. **AI 초안 만들기**: 다섯 단계가 모두 자동으로 채워집니다.
   - ① 영상소스: 직접 촬영본 → 상품 이미지 → 라이선스 스톡 → 생성 카드 순
   - ② 대본: 훅 3안 + 비트별 내레이션. 모든 사실에 근거가 붙습니다. 분량은 20~25초에 맞춰 자동으로 조절됩니다
   - ③ 워터마크: @계정명
   - ④ 보이스: 쇼츠 전용 빠른 보이스 9종 중 페르소나에 맞는 하나를 추천합니다(카드에 속도 ×1.2~1.3 표시). ElevenLabs 키가 있으면 실제 음성
   - (GPT Image 키가 있으면) 문제 장면 비트는 렌더할 때 AI 장면으로 채워집니다. Higgsfield 키까지 있으면 모션 영상으로 채워집니다
   - ⑤ 자막: 스타일·위치
3. **원하는 곳만 수정**: 대본을 고치면 즉시 검사합니다.
   - 빨강(오류): 근거 없는 수치, 효능 표현, 체험 위장, 할인 문구, **25초 초과** → 고쳐야 생성할 수 있습니다
   - 노랑(주의): 최상급 표현 → `제안 적용` 한 번이면 순화됩니다
   - 상품 팩트로 증명되는 문장(예: "리뷰 3,812개")은 근거가 자동으로 연결됩니다
4. **영상 생성하기**: 생성에 약 10~30초 걸리고, 완성 영상은 20~25초입니다. 광고 표기(첫 3초 상단 띠)는 법적 의무라 끌 수 없습니다.
5. **검수 후 게시**: 게이트 통과(PASS) 시 선택한 계정에 자동 분산 예약됩니다.

`전부 자동 생성` 버튼은 2~5를 한 번에 실행합니다.

**쇼츠 길이와 보이스 규칙**: 쇼츠는 20~25초짜리 상품 설명이라 빠르고 간결한 보이스만 씁니다.
- 대본 아래 `예상 영상 길이` 바는 빠른 속도(8음절/초)로 계산합니다. 숫자는 읽는 소리 기준입니다(예: "3,812" → 삼천팔백십이).
- 25초를 넘으면 빨강으로 바뀌고 생성 버튼이 막힙니다. 20초보다 짧으면 마지막 CTA 화면으로 길이를 채웁니다.
- 렌더할 때 실제 말하기 속도를 측정합니다. 7.5음절/초보다 느리면 8음절/초로 올리고, ×1.35로도 못 맞추면 그 음성은 거부합니다.
- 예전에 고른 느린 보이스(따뜻한·차분한·속삭임 등)는 자동으로 가장 가까운 빠른 보이스로 바뀝니다.

**툴 메뉴**
- **컷편집**: 내 영상의 구간만 잘라 새 소스로 저장합니다.
- **이미지→영상 (모션)**: 상품 사진에 줌·팬 카메라 움직임만 더합니다. 상품 자체는 바꾸지 않습니다. 'AI 모션(Higgsfield)'은 AI 생성 장면 이미지에만 고를 수 있습니다.
- **대본 추출**: 권리 원장에 "직접 촬영"으로 등록된 내 영상에서만 쓸 수 있습니다. 타인 영상은 불가합니다(설계서 §8.2). 음성 인식은 서버의 faster-whisper를 쓰고, 없으면 Gemini 키로 처리합니다.

**영상 업로드 규칙**: 직접 촬영했거나 권리를 보유한 영상·이미지만 올릴 수 있습니다. 업로드할 때 확인 체크가 필요하며, 모든 소스는 권리 원장에 기록됩니다.

### C. 글 콘텐츠 (Threads)
스튜디오에서 종류를 `글`로 선택하거나 명령에 "글로"를 넣습니다. 본문 첫 줄에 대가성 문구가 자동으로 들어갑니다.

## 3. 시스템이 절대 하지 않는 것 (설계서 §8.2)
- 타인 영상·음성·자막·이미지의 다운로드·재업로드·재사용
- 클릭 유도, 자동 클릭, 계정 다수 생성, 댓글·좋아요 자동화
- 브라우저 매크로나 비공식 API로 게시 (카카오는 수동 원클릭 큐)
- 실존 인물 사칭, 가짜 사용 후기

## 4. 문제가 생겼을 때
| 증상 | 먼저 볼 곳 | 조치 |
|---|---|---|
| 게시가 계속 대기 | 운영 준비 (토큰·쿼터), 계정 상태 | 쿨다운이면 48시간 후 자동 해제됩니다. 토큰을 재등록합니다 |
| 쿠팡 API 403 | 운영 준비 › 서킷 | 1시간 캐시로 운영한 뒤 1회 재시도합니다(자동) |
| 품절 링크 | 알림 › 링크 상태 | 해당 게시물을 보류하고 대체 상품을 제안합니다 |
| 예산 상한 도달 | 설정 › 일 예산 | 상한을 올리거나 다음 날 재개합니다 |
| AI 장면이 카드로 나옴 | 운영 준비 › AI 연동 (상태), 스튜디오 ① 영상소스 안내 | 키 오류면 키를 다시 등록합니다. 예산 부족이면 예산을 조정합니다. 생성 실패 사유는 ① 영상소스에 표시됩니다 |
| 음성이 Windows 음성으로 나옴 | 운영 준비 › AI 연동 › ElevenLabs | 키 상태를 확인하고 '다시 매핑'을 누릅니다 |
